0.5 Ecosistema de Agentes con Scope Enforcement
17 ago 2026 · en producción
4 canales — Facebook Messenger y TikTok sumados a WhatsApp e Instagram. Workers ARQ completos con flujo idéntico: webhook → tenant → scope prompt → RAG → Brain → API → DB.
7 agentes con scope — WA-Ext, IG-Ext, FB-Ext, TT-Ext (interacción pública) + IG-Int, FB-Int, TT-Int (análisis operativo para el equipo).
app/core/scope.py — Channel + Scope enums, matriz de acciones, ScopeViolationError para enforcement en runtime.
app/core/agent_prompts.py — 7 SCOPE_HEADER prepended antes del custom prompt del tenant. El LLM conoce explícitamente qué puede y qué no puede hacer.
Migración 005: tabla agent_configs con UNIQUE(tenant_id, channel, scope), RLS, trigger updated_at.
Admin API extendida: GET/PUT /api/admin/tenants/{id}/agents/{channel}/{scope} — gestión de prompts por agente desde el panel.
Panel actualizado con sección Agentes — selector de canal + scope, preview del SCOPE_HEADER, prompt personalizable por agente.
0.4 RAG · Knowledge Base por tenant
17 ago 2026 · en producción
RAG per-tenant — documentos indexados con embeddings vectoriales; el agente recupera los chunks más relevantes antes de responder.
Modelo de embeddings: paraphrase-multilingual-MiniLM-L12-v2 (HuggingFace, gratis, 384 dims, español nativo).
Chunking con solapamiento (200 palabras, overlap 20) y búsqueda por similitud coseno con threshold configurable.
API Admin: GET/POST/DELETE /api/admin/tenants/{id}/docs — gestión de documentos con embedding automático.
Panel /panel — sección "Base de conocimiento" con lista de docs, tipos (FAQ/producto/política), badges de chunks y eliminar.
Workers WhatsApp e Instagram actualizados: embed query → cosine search → inject context block en system prompt.
Migración 004: tabla embeddings con VECTOR(384) + índice por tenant.
0.3 Multi-LLM · Admin Panel · Config por tenant
17 ago 2026
Panel de configuración en /panel — UI interactiva con login Bearer token, lista de tenants y editor de config.
