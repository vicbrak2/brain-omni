0.5 Ecosistema de Agentes con Scope
17 ago 2026 · en producción
4 canales — Facebook Messenger y TikTok sumados. Workers ARQ completos: webhook → tenant → scope prompt → RAG → Brain → API → DB.
7 agentes con scope — WA-Ext, IG-Ext, FB-Ext, TT-Ext (público) + IG-Int, FB-Int, TT-Int (equipo operativo).
core/scope.py — Channel + Scope enums, matriz de acciones, ScopeViolationError para enforcement en runtime.
core/agent_prompts.py — 7 SCOPE_HEADER prepended antes del custom prompt del tenant. El LLM sabe explícitamente qué puede y qué no.
Migración 005: tabla agent_configs con UNIQUE(tenant_id, channel, scope), RLS, trigger updated_at.
Admin API: GET/PUT /api/admin/tenants/{id}/agents/{channel}/{scope} + panel con selector canal+scope.
0.4 RAG · Knowledge Base por tenant
17 ago 2026 · en producción
RAG per-tenant — documentos indexados con embeddings; el agente recupera chunks relevantes antes de responder.
Embeddings: paraphrase-multilingual-MiniLM-L12-v2 (HuggingFace, 384 dims, español nativo).
Chunking con solapamiento (200 palabras, overlap 20) + búsqueda coseno con threshold configurable.
Admin API: GET/POST/DELETE /api/admin/tenants/{id}/docs con embedding automático.
Migración 004: tabla embeddings con VECTOR(384) + índice por tenant.
0.3 Multi-LLM · Admin Panel · Config por tenant
17 ago 2026
Panel en /panel — login Bearer token, lista de tenants, editor de config con 5 templates de industria.
Brain orchestrator con rotación dinámica: OpenRouter → Cerebras → HF → Groq. Todos via httpx, sin SDKs.
Canal Instagram DM completo: webhook HMAC, worker ARQ, sender Graph API v20.
18 tests unitarios — parsers WA/IG + verificación HMAC-SHA256.
